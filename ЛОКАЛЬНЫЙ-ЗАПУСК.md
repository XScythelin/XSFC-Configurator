# XSFC Configurator: локальный запуск на Windows x64

## Запуск

Откройте `Запустить.cmd` из полностью распакованной папки. Лаунчер использует
Node.js 24 из `.runtime/node` и открывает Chrome либо Edge в отдельном профиле.
Установка Node.js, npm и Git пользователю не нужна, если в папке есть готовая
сборка `src/dist` и переносимый runtime.

Адрес: **http://127.0.0.1:8081/**. Оригинальный Betaflight на порту 8080
работает отдельно. Локальный сервер раздаёт только файлы интерфейса; связь
с полётным контроллером идёт напрямую через Web Serial → COM/USB → MSP.
Сервер на самом контроллере не требуется.

Снимите пропеллеры, подключите XSFC по USB, выберите COM-порт и подключитесь.
Браузеру нужно разрешение на последовательный порт; при необходимости
установите драйвер USB-устройства. Прошивка через STM32 DFU здесь не используется.

При первом запуске включён экспертный режим, отключена аналитика и включена
настройка лимитного подключения. Это не firewall и не гарантирует отсутствия
сетевых запросов браузера. Настройки сохраняются между запусками.

Закрытие окна браузера не останавливает сервер. Журналы, PID и отдельный
браузерный профиль находятся в `.local-run`. Если порт 8081 занят другим
приложением, лаунчер сообщает об ошибке, не завершая чужие процессы.

## Передача на другой компьютер

1. Подготовьте отдельную копию папки, не меняя рабочие исходники.
2. Исключите `.git`, `node_modules`, `.local-run`, личные дампы и журналы.
   Не передавайте браузерные профили: в них пользовательские данные.
3. Сохраните `.runtime/node`, `src/dist`, `scripts/start-local.ps1`,
   `scripts/serve-local.mjs`, `Запустить.cmd`, исходники и лицензии.
4. Упакуйте папку. На другом ПК полностью распакуйте её, например в
   `C:\XSFC-configurator`, и откройте `Запустить.cmd`.

Не запускайте программу внутри ZIP. Права администратора обычно не нужны.
Этот документ описывает структуру переносимой копии, а не наличие уже
подготовленного ZIP-архива.

## Пересборка для разработчика

После изменения исходников обновите сборку с Node.js 24:

```powershell
$env:Path = (Join-Path (Get-Location) '.runtime\node') + ';' + $env:Path
& '.\.runtime\node\npm.cmd' ci
& '.\.runtime\node\npm.cmd' run build
```

Архив только с исходниками обычно не содержит `.runtime/node` и `src/dist`.
Для переносимого запуска добавьте официальный Windows x64 runtime Node.js 24
в `.runtime/node`, сохранив его лицензии. Папка должна содержать `node.exe`.

Совместимость форм с XSFC API 1.43 проверяется поэтапно. Успешная сборка
не заменяет аппаратную проверку чтения, сохранения, перезагрузки и повторного
чтения настроек. Текущий статус указан в `TODO.md`.
